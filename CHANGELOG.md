# BetterGearing

## v0.3.0

- **Crafting for other players**: inspect someone and click the new BetterGearing icon in the inspect window's title bar (or `/bgear view target`). Tooltips and your profession recipe list then show which of your recipes would be upgrades for them, compared with the gear they wear right now.
- Their spec is read from their talents. Set it yourself with `/bgear view target <spec>`.
- A line above the recipe search box names whose upgrades the arrows show while a preview is on.
- Alt previews (`/bgear view <character>`) now drive the recipe list arrows too.
- Fixed: `/bgear view <class> <spec>` did not accept specs with an underscore, such as `hunter beast_mastery`.

## v0.2.0

- First CurseForge release.
- Items you are already wearing now say **equipped** (in yellow) instead of "about the same", including copies in your bags and recipe results.
- Upgrade arrows after recipe names in the profession window, "equipped" for items you wear, and a dimmed arrow with a level number for recipes that become upgrades within 5 levels.
- The tuning window and README explain how scores, upgrades and percentages work.
